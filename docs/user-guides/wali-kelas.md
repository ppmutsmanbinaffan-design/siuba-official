# Panduan Pengguna — Wali Kelas

## 1. Pemantauan Kehadiran Kelas Binaan
- Buka menu **Laporan Matriks KBM** atau **Dashboard Eksekutif**.
- Anda memiliki akses khusus untuk melihat rekap kehadiran, persentase kehadiran santri di kelas Anda, serta rekap izin/sakit santri.
- Akses ke kelas di luar binaan Anda dibatasi secara ketat demi privasi data.

## 2. Tindak Lanjut Santri Perlu Perhatian (Attention List)
- Di dashboard Anda, periksa santri dengan tingkat kehadiran di bawah 85% atau yang memiliki catatan Alpha > 2 kali untuk dilakukan pembinaan.
