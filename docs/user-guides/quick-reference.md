# SIUBA — Kartu Petunjuk Cepat (Quick Reference Card)

| Situasi Operasional | Solusi / Tindakan Cepat |
|---|---|
| **Santri Hadir Tepat Waktu** | Tap kartu RFID di reader atau scan QR code santri di scanner |
| **Santri Terlambat (<15 Menit)** | Tap / scan kartu. Sistem otomatis menetapkan status *Terlambat* & menghitung menit keterlambatan |
| **Santri Lupa Bawa Kartu** | Buka *Absensi Manual*, cari nama santri, klik tombol **Hadir** |
| **Satu Kelas Hadir Semua** | Buka sesi kelas di *Absensi Manual*, klik tombol hijau **Hadirkan Semua** |
| **Santri Sedang Sakit / Izin** | Ajukan di menu *Izin & Dispensasi*, status sesi otomatis menyesuaikan |
| **Koneksi WiFi Tiba-tiba Putus** | Tetap lanjutkan presensi di aplikasi (tersimpan di antrean offline lokal) |
| **WiFi Kembali Terhubung** | Buka *Pusat Sinkronisasi*, klik tombol **Sinkronkan Sekarang** |
| **Kartu Santri Hilang / Rusak** | Admin: Buka data santri, klik *Regenerate QR Token* / Pasang UID RFID baru |
| **Terminal RFID Tidak Merespons** | Gunakan smartphone operator dengan menu *Live QR Scanner* sebagai cadangan |
